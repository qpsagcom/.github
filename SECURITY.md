# Security Policy

This policy applies to all public repositories of QPS Engineering AG (`qpsagcom`).

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately instead:

- via GitHub's **"Report a vulnerability"** button on the repository's *Security* tab, or
- by email to **info@qpsag.com** with the subject line `Security`.

Please include the affected repository, a description of the issue, steps to reproduce and,
if possible, its potential impact.

We acknowledge reports within five working days and keep you informed until the issue is resolved.
Please give us reasonable time to fix the problem before disclosing it publicly.
